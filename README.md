# 세온비즈 웹사이트

승인한 A 스튜디오 디자인과 B 자료 구성을 결합한 한국어 코칭 사이트입니다.

## 구성

- `/`: 코칭 소개, 업종별 입구, 실제 자료 전환, 스크롤에 반응하는 작업 과정, 가격과 FAQ
- `/coaching/shop`, `/coaching/service`: 업종별 안내
- `/cases`: 고객 검색 기록과 자체 콘텐츠 제작 사례 2편
- `/notes`: 새 코칭 노트 3편
- `/apply`: 무료 상담 신청과 실제 D1 접수
- `/manage`: 접속키로 보호한 상담 접수 관리와 정보 삭제
- `/privacy`: 상담 신청 정보의 수집·이용 안내

## 운영

관리자 접속키는 이 컴퓨터의 `.private/관리자-접속.md`에 보관되어 있습니다. 이 파일과 `.dev.vars`는 Git 및 배포에서 제외합니다. 배포 환경에는 `SEONBIZ_ADMIN_KEY`를 비밀 값으로 별도 설정합니다. 접속키를 바꾸면 기존 관리 세션도 무효화됩니다.

신청은 DB에 저장됩니다. 카카오톡과 문자는 자동 발송하지 않습니다. 관리자가 접수 내용을 확인하고 연락합니다. 상담 목적을 달성하거나 철회 요청을 받으면 관리 화면에서 해당 정보를 삭제합니다.

## 공개 전 남은 입력

- 사용자가 추후 제공하기로 한 카카오톡 상담 주소를 개인정보 문의 경로에 연결
- 실제 운영자의 개인정보 안내 최종 검토
- seonbiz.com 도메인 전환과 기존 사이트 교체를 위한 배포 접근 정보

현재 사이트의 삭제나 도메인 전환은 수행하지 않았습니다. 기존 글을 이전하지 않았고, 고객 실명·도메인·절대 매출을 포함한 GA4 원본은 배포하지 않습니다.

## 개발

`npm run dev`로 로컬 미리보기를 시작합니다. Sites 제작 흐름에서는 해당 스킬의 빌드·배포 절차를 따릅니다. D1 스키마는 `db/schema.ts`, 마이그레이션은 `drizzle/`에 있습니다.

접수 검증은 서버에서 수행합니다. 저장 실패 시 완료로 표시하지 않으며 입력 내용을 유지합니다. 동일 요청 ID 재시도는 중복 저장하지 않습니다. 관리 요청은 별도 인증과 동일 출처 검사를 통과해야 합니다.
